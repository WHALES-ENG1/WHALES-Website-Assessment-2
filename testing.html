Manual Tests

Each of the following tables represents one of the manual test protocols for our project.
ID MT_SCREEN_SCALING Related Requirements/Components UR_SCREEN_SCALABILITY
NFR_SCREEN_SCALABILITY
Description Does resizing the game window behave as expected? We should have no overlap of GUI elements and rendering should function normally on a variety of different window sizes.
Steps
  1. Run the game executable.
  2. Resize the game window in each of the following ways:
    1. Default windowed size (no resize from load)
    2. As small horizontally and large vertically as possible
    3. As large horizontally and small vertically as possible
    4. As small as possible on both axis
    5. Game window maximised
  3. Navigate through the menus to start the game, then repeat step 2.
  4. Repeat step 2, but with the game paused.
Expected Outcome All game elements continue to render. No noticeable size disparity between sprites. UI elements do not overlap.
Person Responsible Samuel Knight
ID MT_UE_FAMILY_FRIENDLY Related Requirements/Components UR_FAMILY_FRIENDLY
Description Testing whether the game is considered to be appropriate for young audiences, based on public opinion.
Steps Test to be completed using the User Evaluation form. Evaluators will be asked to evaluate whether they believe the game is appropriate for young audiences.
Expected Outcome >90% of evaluators answer positively when asked if they think the game is appropriate for young audiences.
Person Responsible Leo Durnion
ID MT_BBFC_FAMILY_FRIENDLY Related Requirements/Components UR_FAMILY_FRIENDLY
NFR_NO_GRAPHIC_CONTENT
Description More objective testing of how family friendly the game is based on the BBFC PG rating guidelines.
Steps Analyse the content of the game looking for the following content:
  1. Look for any instances of violence or dangerous behaviour and ensure that it isn’t “presented as safe or fun”
  2. Any uses of discriminatory language should be clearly disapproved of.
  3. References to illegal drugs or drug misuse should be brief and carry a suitable cautionary message.
  4. There may be mild bad language only.
  5. There may be nudity with no sexual context.
  6. Sexual activity may be implied, but should be discreet and infrequent. There may be mild sex references and innuendo only.
  7. Threat and scary scenes should not be prolonged or intense.
  8. Violence will be mild, with more impactful moments permitted if justified by context. Injury detail, including sight of blood, should be brief.
All parts of the game should be suitably evaluated for these criteria
Expected Outcome >90% of evaluators answer positively when asked if they think the game is appropriate for young audiences.
Person Responsible Anexa Bijoy
ID MT_UE_MAP_ACCURACY Related Requirements/Components UR_UNIVERSITY_ACCURATE
NFR_UNIVERSITY_STUDENT_RELATABLE
Description Is the map accurate to some part of the university? It must recognisably match some area of the university, with some liberties allowed.
Steps Test to be completed using the User Evaluation form. Evaluators will be asked to evaluate whether they think the map resembles any part of the university.
Expected Outcome >50% of evaluators answer positively when asked if they think the game resembles any part of the university. This is a lower percentage than MT_UE_FAMILY_FRIENDLY since there is some leeway in how closely the map matches according to UR_UNIVERSITY_ACCURATE.
Person Responsible Leo Durnion
ID MT_SPRITE_DISTINGUISHABILITY Related Requirements/Components UR_COLOURBLIND_FRIENDLY
NFR_COLOURBLIND_FRIENDLY
Description Ensuring the game's assets are easily distinguishable from each other under a variety of colour blind filters in order to make sure the game is playable by people with various types of colourblindness.
Steps
  1. Run the game executable
  2. Play through a run of the game as normal, record any places where sprites are hard to distinguish from each other when they shouldn’t be.
  3. Launch Color Oracle and apply each of the following filters on every screen encountered, repeating steps 1 and 2 for each filter.
    1. Deuteranopia
    2. Protanopia
    3. Tritanopia
    4. Greyscale
(Note: Color Oracle will only show you a snapshot of your screen with the given filter, you’ll need to apply the filter for each screen individually. When you launch Color Oracle, it doesn’t have a window, and instead loads to your system tray)
Expected Outcome No instances of indistinguishable sprites under any filter.
Person Responsible Samuel Knight
ID MT_UE_DIFFICULTY Related Requirements/Components UR_BEGINNER_DIFFICULTY
NFR_BEGINNER_DIFFICULTY
Description Checks that the game isn’t too difficult for players ensuring it is beginner-friendly.
Steps Test to be completed using the User Evaluation form. Evaluators will be asked to rate the difficulty of the game from 1 to 5, with 5 being the most difficult and 1 being the easiest
Expected Outcome Mean difficulty rating less than or equal to 3.
Person Responsible Leo Durnion
ID MT_UE_LEGIBILITY Related Requirements/Components UR_LEGIBLE_TEXT
NFR_LEGIBLE_TEXT
Description Is the text rendered on the screen readable to all users, and does it adjust the resolution to fit different sized devices?
Steps Test to be completed using the User Evaluation form. Evaluators will be asked to evaluate whether the text shown to them on the screen was legible. They will be asked: "Was the text easy to read?", "Did you have any difficulty distinguishing between words or characters?".
Expected Outcome >90% of evaluators must answer positively when asked if text on the screen was legible.
Person Responsible Anexa Bijoy
ID MT_PAUSE_GAME Related Requirements/Components UR_PAUSE
Description Ensuring that pausing the game works effectively in all possible situations of gameplay.
Steps
  1. Run the game executable
  2. Play through a run of the game as normal, pausing at random times throughout gameplay
  3. When transitioning to another room, or when an event is activated, pause the game to see if it works as normal
Expected Outcome Pausing the game works the same in all circumstances.
Person Responsible Leo Durnion
